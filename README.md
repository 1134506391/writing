# 雅思写作练习记录

## 目录结构

```text
writing/
├── README.md              # 本文件:方法和索引
├── error-log.md           # 累计错误统计和自查清单
├── grammer.md             # 语法笔记:介词、连接词位置、respectively 等
└── task1/
    ├── 柱图/
    │   ├── article/       # 一篇范文一个文件:01-交通事故.md … 08-电子游戏.md
    │   └── question/      # 原图:01.png … 08.png(和 article 里的编号对应)
    └── 表格/
        ├── article/       # 01-地下铁.md
        └── question/      # 01.png
```

- 每种题型单独编号(柱图 01–08,表格 01 开始)。
- 图片放在 `question/`,编号和 `article/` 里的文件对应(`01.png` ↔ `01-xxx.md`)。
- 范文文件里用相对路径引用原图:`![原图](../question/01.png)`。

## 每篇范文的固定流程

1. 读原范文和 Claude 的修改版,弄懂改动原因。
2. 不看答案,自己写**版本 1**,原样存入,**不要事后改动**。
3. 请 Claude 逐句批改(语法、拼写、搭配、内容是否和图一致),写入「版本 1 逐句批改」。
4. 把错误类型登记到 `error-log.md`。
5. 不看批改,重写**版本 2**,存入文件。
6. 对比版本 1 和 2:哪些错误消失了,哪些还在。
7. 隔几天再写**版本 3**(不看任何批改),检验是否真的改掉了。版本 2 是批改后立刻写的,测的只是短期记忆。

## 版本约定

| 名称 | 含义 |
| --- | --- |
| 原范文 | 资料里的范文,不动 |
| 参考修改版 | Claude 改进后的范文 |
| 版本 1 | 你的初稿,原样保留 |
| 最小修订 | 只改错、保留你的思路和用词 |
| 版本 2、3… | 你看过批改后的重写 |

## 用 Git 管理版本(可选,但推荐)

```bash
git init
git add . && git commit -m "01 交通事故 v1"
# 重写后
git add . && git commit -m "01 交通事故 v2"
git diff HEAD~1 -- task1/01-交通事故-柱图.md   # 看两次的差异
```
